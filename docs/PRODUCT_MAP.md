## Current build order

1. Complete and test source → durable claim → private pass → redemption → confirmed optional subscription → scheduled Drop → recorded return.
2. Give operators a useful Today inbox and real controls for that loop.
3. Turn the merchant home into a managed Growth Plan, with one evidence-supported next action.
4. Make the physical network visible through named placements and an explicitly schematic map.
5. Expand Offer Studio with goals, template library, editable estimates, deterministic quality checks, and screen/pass/SMS previews from the same draft.
6. Add audience and careful return metrics. Insufficient evidence says “Still learning.”

## Product rules

- No inferred screen impressions, message reads, new customers, revenue, ROI, or physical non-return.
- Offer economics are merchant-entered estimates, not profit calculations.
- A recorded return requires a later Drop redemption after an initial redemption; show denominator and observation window.
- Unchecked consent is optional. Link previews do not confirm phone possession.
- Test/sample businesses remain explicitly local and never imply production results.
- No runtime LLM, arbitrary segmentation builder, screen playback, billing, POS integration, pricing intelligence, or advanced experimentation in this pilot.
- Keep immutable offer/source/creative context so later learning has a trustworthy foundation.
